# Бортовой регистратор энергии (прототип в Wokwi)

## Зачем это

Заявленная экономия 357 МВт·ч — расчётная цифра для Польши. Чтобы КТЖ принимало решение по реальным данным, на вагонах нужно **измерять** фактический расход энергии. Этот прототип показывает, как работало бы такое устройство на ESP32.

В прототипе два поезда (145 т и 180 т) едут по одному графику, а устройство считает кВт·ч на километр для каждого и экономию алюминия в процентах. В реальном устройстве вместо физической модели стоят датчики тока и напряжения, а данные уходят на сервер по MQTT.

## Управление

| Элемент | Пин | Что делает |
|---|---|---|
| Потенциометр 1 | GPIO34 | расстояние между остановками, 1–100 км |
| Потенциометр 2 | GPIO35 | рекуперация, 0–60 % |
| Кнопка STOP | GPIO13 | внеплановая остановка |
| Кнопка RESET | GPIO14 | сброс счётчиков |
| Зелёный светодиод | GPIO26 | тяга |
| Красный светодиод | GPIO27 | торможение |
| Дисплей LCD 2004 (I2C) | 21, 22 | показания |

Serial Monitor выводит телеметрию в формате JSON раз в секунду.

## Как запустить

1. Откройте [wokwi.com](https://wokwi.com) → **New Project** → **ESP32**.
2. Вставьте содержимое `sketch.ino` и `diagram.json` в одноимённые вкладки.
3. Создайте файл `libraries.txt` со строкой `LiquidCrystal I2C`.
4. Нажмите ▶.

## Что показать

Ручка 1 влево (частые остановки) → RESET → экономия около 12 %.
Ручка 1 вправо (редкие остановки) → RESET → экономия падает до 7–8 %.
